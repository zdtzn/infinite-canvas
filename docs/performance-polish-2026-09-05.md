# Infinite Canvas 无损性能优化结果

日期：2026-09-05。分支：`performance-polish`。

基线：`00540dbdd80e76d9fa72d6f0ccf423899f374472`，从 `origin/main` 创建独立分支，保留基线中的最新徽章修复。本轮尚未提交、推送、合并或部署。

## 结论

实施了首轮低、中风险优化，主要收益在首屏负担、首页封面数据和长聊天输入。不是完成了审查中的全部建议，也不是所有指标都下降。

架构、依赖版本、配色、布局、动画素材、图片编码、原图导出、生成流程、任务系统、额度、自动保存间隔和手动入藏规则未作调整。

## 已实施

| 范围 | 修改 | 保留边界 |
| --- | --- | --- |
| 首页封面 | 增加只返回封面元信息的索引接口，首页不再为了轮播拉取全部提示词正文 | 保留所有启用来源、排序、50 张展示窗口、90 秒轮换及原图预览；缺失索引或旧服务端走原来源回退 |
| 首屏代码 | 登录表单按需加载；首页背景预加载移入首页路由；空闲预热最多三个现有高优先级入口 | 不移除其他入口，仍保留导航意图预加载；非预热页面的首次打开成本未声称消失 |
| 问道台预取 | 单纯预加载聊天代码不再自动取会话，明确导航意图仍预取 | 不修改历史会话、角色和上下文数据 |
| 长聊天 | 历史气泡 memo、稳定操作回调、滚动测量按动画帧调度并取消 | 不做虚拟列表，不改流式字符、复制、编辑、重试、表格和代码块语义 |
| 请求 | 按账号合并进行中的偏好读取，写入前后失效；取消已过期的藏卷阁搜索 | 无新增成功响应长期缓存，不合并生成或保存请求 |
| 画布 | 节点根查找复用映射；云端项目比较改用 Set/Map | 不改节点位置、缩放手感、撤销、冲突处理和保存时机 |
| 图片代理 | 同键并发下载共享；异步、有并发上限的目录扫描；清理和访问时间更新合并 | 一个调用方取消不影响其他人；全部取消才中止下载；写后仍等待清理以保留容量约束 |
| 资源释放 | 图片解码失败释放 ObjectURL；异步读取后复查已生成地址；删除无用媒体时释放地址；音视频元信息读取后卸载元素 | 未加入新的有损缩略图；同键导入替换的提前 revoke 已撤回，避免现有引用失效 |

缓存扫描保留原有尽力而为的容错，目录暂不可读不阻断服务启动，实际删除失败仍向上传递。

## 构建对比

以下单位为字节。gzip 为各文件独立压缩后求和，不代表浏览器首屏下载全部文件。

| 指标 | 基线 | 最终构建 | 说明 |
| --- | ---: | ---: | --- |
| 全部 JS | 4,254,496 | 4,260,383 | 增加 5,887，约 0.14% |
| 全部 JS gzip | 1,432,114 | 1,437,055 | 增加 4,941 |
| 入口 JS | 971,330 | 933,873 | 减少 37,457，约 3.86% |
| 入口 JS gzip | 319,672 | 306,927 | 减少 12,745，约 3.99% |
| 全部 CSS | 338,662 | 338,662 | 不变 |
| 全部 CSS gzip | 61,560 | 61,560 | 不变 |
| 入口 CSS | 200,235 | 200,235 | 不变 |
| 入口 CSS gzip | 33,664 | 33,664 | 不变 |
| 构建时间 | 14.69 秒 | 13.15 秒 | 单次构建，不能当作稳定提速比例 |

结论：减小的是入口负担，不是总 JS。新增轻量辅助逻辑和拆分边界略微增加总产物。

## 浏览器测量

环境：本地 Chrome、1440×900、5 Mbps 上下行、40 ms 延迟、2 倍 CPU 降速。每轮新建浏览器上下文，使用普通用户测试账号。最终构建再次进行三轮前后复测。

| 指标 | 基线三次 | 优化后三次 | 中位数 |
| --- | --- | --- | --- |
| 首页主按钮出现 | 3938.6 / 3899.7 / 3908.5 ms | 3574.7 / 3631.7 / 3600.1 ms | 3908.5 → 3600.1 ms，约快 7.9% |
| FCP | 2572 / 2556 / 2548 ms | 2192 / 2204 / 2204 ms | 2556 → 2204 ms，约快 13.8% |

主按钮出现使用可见性检查作为首屏代理指标，不等于全部图片或全部后台请求完成。前一轮曾观察到更大的改善，本报告以最终重复测量为准，不挑选最快样本。

两侧均使用同一测试后端、独立临时数据库，前端分别使用原构建和优化构建。固定为 120 张封面的测试来源；来源配置响应被测试浏览器替换，外部网络请求被阻止。不是生产网速测量，也不是旧后端与新后端的延迟压测。

### 图片与数据

- 固定 120 条来源的数据响应约 97,090 → 15,606 字节，减少约 84%；这是封面元数据减小，不是压缩图片。
- 未登录页不再下载原本不显示的首页背景，少传约 188 KB。实际登录背景保持不变。
- 构建内 650 个位图、SVG、LUT 文件，共 51,989,918 字节，前后逐文件字节一致。CSS 字节未改变。
- 登录页截图在 1,296,000 像素中，没有像素超过 RGB 绝对差值之和 12 的比较阈值；此为容差比较，不称为严格逐像素相等。
- 未重编码生产用户原图，也未在生产批量读取图片；不能把构建资源一致性称为全库用户原图验收。

### 问道台与内存

- 120 条消息下输入 96 个字符，浏览器主线程 TaskDuration 单次样本为 2849.517 → 523.364 ms，前后输入完整。该指标不是单次按键延迟，不外推为全设备提速比例。
- 连续 48 次站内导航，即问道台、藏卷阁、灵彩、丹青台的 12 轮切换，在第 1/6/12 轮强制 GC 后采样。
- 基线 JS heap：12,494,504 / 15,564,028 / 16,263,248 字节。
- 优化版 JS heap：13,003,268 / 15,424,688 / 16,266,596 字节。
- 最后两次采样事件监听器均为 513；DOM 节点基线为 604/604，优化版为 607/607，没有继续增长。
- 内存总体基本相同，没有证据声称内存明显下降。此项不是 30 分钟压力测试，也未测后端 RSS。

### API 请求数

- 首页静置 20 秒，基线 11 次 GET；优化版 11 次 GET，加一次偏好初始化 PUT。本场景没有总请求数下降。
- 并发同账号、同键读取合并由回归测试验证；非并发读取仍按原逻辑发生。
- 已发现的两次认证状态读取仍存在，本轮没有重构账号隔离与 AuthGate 挂载结构。
- 提示词图片代理的并发合并和取消由测试验证；实际生产缓存目录扫描耗时尚未压测，不能承诺图片展示减少多少秒。
