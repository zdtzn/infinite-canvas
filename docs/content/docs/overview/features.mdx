# 功能介绍

无限画布是一套以 AI 图片创作为核心的工作台。修炼系统负责成长反馈、额度和能力管理，但不会替代画布与生图主流程。

## 账号与数据隔离

- 正式构建要求登录后使用，首次管理员通过服务器回环接口初始化。
- 成员使用站点口令、独立昵称和个人密码登录，管理员可停用成员或关闭新用户加入。
- 项目、素材、头像、生成历史、任务和修炼数据均绑定 `user_id`。
- 素材文件和任务结果通过鉴权接口读取，不能仅凭其他用户的资源标识直接访问。
- 同一账号在其他设备登录后可恢复服务端保存的项目、素材和历史记录。

## 管理员渠道

- 管理员统一添加、修改和删除平台模型渠道。
- API Key 由 Bun 服务端使用 AES-GCM 加密保存，普通用户不会获得明文密钥。
- 普通用户可直接选择管理员开放的渠道与模型，无需自行配置接口。
- 支持 OpenAI 兼容图片接口、Gemini 图片接口、UU API 异步图片任务及自定义兼容调用方式。
- 模型列表读取、上游错误解析、请求超时和渠道用量统计由服务端统一处理。

## 丹青台

- 支持文生图、参考图生成、局部编辑和多图结果。
- 比例、输出分辨率、模型质量与图片格式分开选择，具体生效范围取决于上游模型能力。
- 参考图支持上传、粘贴、从藏卷阁选择和复用生成结果。
- 生成历史可查看、删除、重试、下载或将作品收入藏卷阁。
- 任务状态区分排队、提交、上游生成、成功、失败与取消，并显示可理解的错误信息。

## 持久生图任务

- 服务端为每次生成创建唯一任务 ID，并在 SQLite 中持久化状态。
- 额度预占、并发校验、任务创建和修为结算由服务端控制。
- 失败或初始化异常会按规则返还额度，成功任务只结算一次修为。
- 页面刷新、跨页面切换和部分服务重启场景可以恢复任务状态。
- UU 异步任务保存远端任务 ID，可继续轮询并支持远端取消。

## 无限画布

- 支持多画布项目、新建、重命名、删除、导入、导出和服务端自动保存。
- 支持画布平移、滚轮缩放、缩放滑杆、重置视图、小地图和多种背景。
- 支持框选、多选、复制粘贴、删除、撤销重做和节点连线。
- 支持图片、文本、生成配置、视频、音频及官方节点插件。
- 图片工具包含裁剪、蒙版、切分、放大、多角度变换和生成子节点。
- 大量节点时对不可见节点和连线进行视口裁剪，减少无意义渲染。
- 多标签页通过项目写锁和版本冲突检测避免同时覆盖同一画布。

## 画布助手与本地 Agent

- 画布助手可读取选中节点和上游节点，进行问答或生成图片并插回画布。
- `@` 引用可直接选择图片、文本、视频和音频资源。
- 本地 Canvas Agent 通过 MCP 让 Codex / Claude Code 读取、创建和连接画布节点。
- Agent 请求与发起标签页绑定，并校验工具结果归属，避免多标签页串线。

当前 npm 包仍由上游维护者发布，命令保持为：

```bash
npx -y @basketikun/canvas-agent
```

## 藏卷阁与生成历史

- 图片、视频、音频、头像和作品文件在正式模式下保存到服务端 `/data`。
- 藏卷阁元数据和文件均按用户隔离，删除素材不会影响其他账号。
- 生图和视频历史同步到服务器，并保留浏览器侧用户隔离缓存以改善加载体验。
- 文件上传会校验类型、大小和图片尺寸，并受每用户存储配额限制。

## 提示词库

- 内置多个可信提示词来源，并支持搜索、筛选、详情、原图查看和下载。
- 正式模式只运行受信任的来源适配器，不执行普通用户提交的任意抓取脚本。
- 提示词图片通过服务端受控代理与磁盘缓存获取，包含超时、来源限制和缓存回退。

## 修炼成长

- 境界、星级、修为阈值、每日次数、并发数量和能力键均由后台配置。
- 同一大境界内与跨境界升级均按当前自动策略结算，管理员仍可手动调整用户数据。
- 每次成功生成按配置增加修为；失败、取消或重复回调不会重复奖励。
- 用户页只展示当前境界、成长进度、额度和必要统计，修炼系统保持为轻量反馈层。
- 斗帝身份样式只影响符合条件的用户，并可关闭帝临模式。

## 后台与运维

- 管理员可管理成员、平台渠道、修炼配置、修为流水、用量、任务和日志。
- 渠道面板展示近期成功率、耗时和运行中任务。
- SQLite 使用 WAL，并在启动时执行版本化迁移；旧 `state.json` 可无损导入。
- 服务端定期使用 SQLite 原生能力创建一致性快照、校验完整性并清理过期备份。
- `/health` 返回版本、提交、数据库、磁盘和关机状态，容器带健康检查与平滑退出。

## 两种运行模式

### 正式服务端模式

Docker 构建后的前端由 Bun 单体服务提供，账号、SQLite、服务端渠道、用户隔离和任务队列全部启用。这是多人部署应使用的模式。

### 本地前端模式

直接运行 `web/bun run dev` 时，前端使用浏览器本地项目、素材和接口配置，适合 UI 调试或可信的个人环境。该模式不代表正式部署的数据安全模型。

WebDAV 在两种模式下都只是可选同步/备份工具，不会同步平台 API Key，也不能替代正式服务端的数据卷备份。
