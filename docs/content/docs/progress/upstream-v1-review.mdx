# 上游 1.0 变更对比

最初核对固定于以下提交，后续上游更新需要另行比较：

- 最初核对分支：`zdtzn/infinite-canvas@368904429de6536c9448e0382e6e7714b4006a97`，与本次获取的 `origin/main` 一致。
- 上游：`basketikun/infinite-canvas@4c67f1ece4f4edaef81e58e964eb78abb1e9809d`。
- 重构前对照：上游 `9cd3deacbc`；当前分支此前已通过 `7cf559a`、`ccadd33` 等提交选择性移植过渲染与交互改进，后续也适配了参考栏和分组引用。

核对期间工作区另有未提交的画布生图与批次修复，本次保留这些内容；它们不计入本次截帧移植和定向测试结论，合并统计仍以以上固定提交为准。

建议继续独立维护当前的多人服务架构，选择性吸收上游功能。上游 1.0 更适合个人本机工作台；当前项目的账号隔离、云端素材、灵卷结算和持久生图任务需要保留。

1.0 的具体变化：

- 代码组织改为 pnpm workspace，入口位于 `apps/cli`、`apps/desktop`、`apps/web`，共享能力放在 `packages/workbench`、`shared`、`server`、`model-runtime` 和 `plugin-sdk`。桌面版通过 Electron 打开同一个本地服务。
- 图片和视频创作合并为对话式创作页。画布聊天通过渠道文本模型调用画布工具，CLI 和桌面版对外提供 MCP。
- 插件由节点扩展升级为工作台扩展，可注册页面、导航、布局、主题、工具、模型调用方式及同步方式，支持市场安装、更新和插件包上传。
- 新增 3D 导演台：角色与道具摆位、机位和移动轨迹、环绕镜头、截图及无声录像回传画布。另提供主题、调用统计、多格式渲染、全景及 WebDAV 插件。
- 调用脚本模块覆盖更多协议，包括 Anthropic、Kling、Hailuo、Wan、Vidu、xAI、Grok2API 等；这表示源码包含对应脚本，不代表已经用当前平台渠道实测。
- 资产增加文件夹整理。S3 兼容对象存储可为需要公开链接的参考素材提供上传能力。
- Web 使用新的 `infinite-canvas-v1` 数据库，明确不自动读取 0.x 数据；CLI 数据保存在本机工作区。

## 冲突与方案取舍

使用 Git 2.54.0，在当前 Git 配置下模拟两个固定提交的整分支合并，报告 **1,028 个冲突路径**。其中包含目录重命名、文件搬迁和修改/删除冲突，并非 1,028 个独立的业务缺陷。模拟只生成 Git 合并树，没有把合并结果应用到工作区。

```bash
git merge-tree --write-tree --name-only 368904429de6536c9448e0382e6e7714b4006a97 4c67f1ece4f4edaef81e58e964eb78abb1e9809d
```

冲突集中在 `packages/workbench`、原 `web/src`、新旧文档目录、Agent 插件入口、`Dockerfile` 和发布工作流。

## 首轮截帧移植与验证

适配自上游 [canvas-video-frame.ts](https://github.com/basketikun/infinite-canvas/blob/4c67f1ece4f4edaef81e58e964eb78abb1e9809d/packages/workbench/src/lib/canvas/canvas-video-frame.ts)：

- 视频截帧等待 `canvas.toBlob` 时，取消或超时立即结束等待，不依赖浏览器编码回调到达；迟到的编码结果不会继续生成截帧文件。
- 视频暂停、移除资源或重新加载发生异常时，仍释放临时视频 URL。
- 保留现有文件大小、时长、像素限制、媒体事件超时、账号/项目归属保护和画布插入流程。

定向回归覆盖正常 PNG、编码中取消及迟到回调、空编码结果、编码同步异常、视频清理异常。修改前 2 项失败，修改后 5 项通过。本次测试执行时未找到 Bun，执行的是相同测试源码的临时副本，仅将测试入口换成 Node `node:test` 并补全模块路径，直接调用仓库中的 TypeScript 实现；没有执行构建、完整 Bun 套件或真实浏览器媒体验收，也没有调用付费渠道。

## 本轮新功能已完成

- **3D 导演台**：沿用上游三维编辑器，在隔离文档中运行；通过当前节点注册表内置入口，支持角色/道具、机位、轨迹、环绕镜头、拍照及无声录制。场景保存在节点元数据中，附属文件走当前素材存储并以 `storageKey` 关联，沿用项目导出与账号权限。打开时按需加载三维代码，浅深主题跟随画布，窄屏使用场景/属性抽屉。保存等待画布写入并确认 IndexedDB 落盘，失败保留重试；跨账号或项目结束旧会话，回传前再次检查目标节点。
- **账号素材文件夹**：新增层级目录、重命名、调整上级、筛选及批量移动。正式模式保存在当前账号的服务端偏好中，修改使用版本校验；删除时在同一事务中把素材移到仍存在的上级，不删除文件。目录结构随素材 ZIP 导出，导入合并同名层级并重映射 ID；原分类和标签继续使用。本地模式使用 IndexedDB。WebDAV 目录树仍未纳入本轮。
- **11 种本地调用预设**：覆盖 Messages/Anthropic、Agnes、Kling、MiniMax、Wan、Vidu、Grok 和 Grok2API。保留已有异步函数体脚本，新增 `main(params)` 入口与 SSE 事件解析器。查询限制 30 秒，提交最多 10 分钟；异步视频立即保存渠道任务 ID，恢复只查询同一任务，并校验原账号、模型和调用源码。公网参考链接要求在提交前检查，本机素材不会伪装成公开链接，S3 上传未接入。托管渠道的服务端执行与计费继续沿用当前实现。

入口：画布“新建节点 → 3D 导演台”、藏卷阁的文件夹工具、本地模型脚本编辑器的“选择上游调用预设”。

**本轮验证**：62 项定向 Bun 测试通过，包含 SQLite 账号隔离、目录版本冲突与事务回滚、素材包目录重映射、跨账号导入中断、机位布局与撤销、场景存储失败重试、原视频任务恢复、多个协议参数、SSE 中文分片，以及已有生图与视频流程。隔离 Chromium 在 1366px 与 390px 验证实际编辑器渲染、环绕镜头、PNG 截图、短片录制、回传与保存关闭，以及文件夹创建和批量移动，未出现浏览器运行错误。

测试使用临时页面、浏览器数据和 SQLite，没有访问生产账号、调用付费模型或验证真实供应商渠道；没有执行生产构建或完整测试套件。源文件、MIT 许可、更新说明、TODO 和待测试清单已同步。
