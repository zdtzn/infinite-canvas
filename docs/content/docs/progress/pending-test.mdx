# 待测试

- 灵彩 RGB 点曲线：在 RGB、R、G、B 四个通道分别点击曲线添加控制点，拖动改变输入与输出值，使用方向键微调，并通过双击或 Delete 删除中间点；确认端点不会横向越界、当前通道可单独重置、撤销重做和草稿恢复正常。连续拖动时预览应保持跟手，停手后自动恢复高清画面；导出结果应与最终预览一致，旧版三段式曲线草稿升级后不丢失原有调色效果。

- SADAI 生图显示与归档：使用 SADAI `gpt-image-2` 分别生成 1K、2K、4K 图片，确认 Base64 结果可正常转为本站图片文件并预览；结果出现后加入藏卷阁、下载和加入参考图仍正常，SADAI 不再把不可访问的临时 URL 当作可展示结果。

- 问道台首屏加载：使用冷缓存首次进入问道台，确认空白状态先显示且不等待 Markdown/Mermaid；收到回答后 Markdown 正常渲染，弱网或省流量模式下不触发无意义的路由预热。

- 灵彩智能抠图：在生产域名上传人物或商品图片后执行抠图，确认首次模型加载不会被内容安全策略拦截或提示 `Failed to create session`，加载期间有明确进度，完成后能拖动分界线检查发丝和主体边缘；分别调整边缘增强、边缘柔化和去除边色，切换棋盘格/白底/深底预览，确认原图不变、透明 PNG 可导出，并可将结果作为新的灵彩草稿打开。用不同尺寸和透明/复杂背景图片确认结果质量、浏览器缓存后的二次处理速度，以及不支持 WebGPU 时仍能使用 CPU 完成。
- 斗气人生：分别创建普通角色和随机角色，确认世界、角色、NPC、背包、功法、战斗和记忆仅属于当前账号；首次进入应在开场叙事下显示观察、查看自身、向前探索和尝试修炼等首轮建议；连续点击行动或重复提交时只产生一轮世界回应，AI 不替玩家说话、决定或行动；验证时间推进、斗气/生命/金币/物品/功法/战斗边界，以及读取、删除手动存档和从存档续行。离开一段现实时间后重新进入，确认世界日期和时间继续推进、时间驱动事件只出现一次、自动存档同步更新；流式回应进行中不应被离线推进重复结算。非战斗时点击暂停修炼不应要求时长或推进闭关；战斗中应可使用攻击、斗技、防御、移动、观察、道具和逃离；行动区应显示“你准备如何行动？”，自由行动只聚焦输入框而不自动提交观察。回应进行时切换人生、新建人生、删除当前人生、读取存档或切回普通问道，确认会先提示并可停止当前请求，已收到的内容保留；刷新或服务重启后，遗留的推演状态应显示失败并可重新行动。非 JSON 文本模型响应仍应作为普通世界叙事显示，剧情消息应按叙事时间线展示，天地流转消息使用独立样式。
- 斗气人生长期记忆：连续完成超过 16 轮行动并刷新或切换页面，确认人生摘要、关键事实、NPC 关系变化和未完成目标仍保留；确认模型上下文只携带有界摘要与最近消息，旧消息被裁剪后仍能引用关键选择；用旧格式存档恢复时确认新记忆字段自动补齐，摘要不会无限增长，寿元终局不会继续产生未完成目标。
- 问道台会话角色绑定：分别以猫娘、墨玄创建并发送消息，切换到其他页面再打开历史会话，确认每段会话恢复各自角色；在同一会话切换角色时确认弹出“新角色只对后续消息生效，历史回答不会改写”，取消后角色不变，确认后只有后续回答使用新角色；刷新或换设备后角色绑定仍保持。旧会话因历史没有保存角色，会按通用问道兼容。
- 问道台会话保护与重试：首次进入且没有历史问道时直接输入文字或只上传图片，确认会自动创建会话并立即显示用户消息；回答流式进行时切换其他会话、新建会话、删除当前会话，确认会先弹出确认并在确认后停止当前请求，已收到的回答内容保留，取消确认则继续原回答；删除其他会话不影响当前回答。点击失败回答的“重试”，确认原用户问题和图片只保留一份，原回答消息恢复流式并最终更新；离开页面或刷新后运行中的回答应中止，重新进入不会留下转圈中的消息。
- 问道台多模态上下文与额度：发送纯图片问题，确认后续文字轮次仍能引用图片；连续多轮带图对话确认历史图片按服务端附件预算恢复，超出字符或图片预算时优先保留较新的上下文且文本问答仍可继续。将 `CHAT_DAILY_LIMIT` 设为较小值验证达到上限后服务端拒绝新请求、重试也计入一次请求且不会插入重复消息；管理员账号的用量查询不显示普通用户上限。
- 问道台流式异常：用会返回正常结束事件、提前断流、结构化错误、空内容和 `[DONE]` 的文本渠道分别验证；只有收到明确完成事件且有正文才标记完成，提前断流保留失败回答并显示重试入口。
- 问道台会话导入导出：导出当前会话后删除或切换会话，再导入 JSON 文件，确认会创建新会话、原会话不被覆盖、角色预设恢复；同一账号仍存在的图片素材可以显示，缺失素材被安全跳过，导入文件中的渠道和模型字段不会改变后台配置。
- 灵彩草稿与调色：在同一账号依次打开同一原图两次，分别做不同调色后刷新页面，确认两个版本都独立保留；切换账号时不能看到另一账号草稿。公网环境打开同一账号的第二台设备，确认草稿会在短暂同步后出现，连续拖动滑杆不会持续重复请求。删除当前草稿或列表草稿后刷新确认不再出现；若网络删除失败，草稿应恢复并提示。把原图或借色参考图删除时应被引用保护。画布素材选择弹窗应优先加载缩略图；超过上传限制的大图入藏或回画布应自动压缩并给出明确提示。
- 灵彩胶片 LUT：打开“胶片滤镜”面板，确认清单可按类别筛选、按名称搜索并分批加载，缩略图按需加载；选择任意 LUT 后实时预览和导出结果应一致，调整强度为 0/50/100 应分别生效，清除后恢复普通调色；切换草稿、刷新和重新进入后选中的 LUT 与强度仍保持。用冷缓存或临时请求失败模拟清单和单个 `.cube` 文件后再次点击，确认可以重试而不是永久显示失败；确认普通色彩秘卷、AI 炼彩、借色、抠图和原图不受影响。
- 灵彩吸色器：点击预览区吸色按钮后在原图和调色结果区域各取样一次，确认右侧出现对应色块及 HEX、RGB、HSL 值，点击结果可复制当前格式；按 Esc 可取消吸色，吸色不会修改调色参数，切换原图、缩放、拖动画布和切换草稿后仍不会出现错误或误触发平移。
- 首页功法精选悬停：桌面端将光标停在任意画卷后，在画卷内部向上、向下及左右连续移动，当前画卷应保持稳定且列滚动与整体视差不抖动；只有光标真正离开当前画卷后才切换到相邻画卷，点击预览与键盘聚焦仍应正常。

- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
