# 待测试

- UU 参考图生图：重新上传一张大于 1280px 的参考图，分别以 1K、2K、4K 提交，确认请求走 `/v1/images/edits` 并正常返回图片；1K 应使用最长边 1280px 的 WebP 轻量副本以缩短传输时间，2K/4K 应继续使用原图。无参考图文生图仍应走 `/v1/images/generations/async`，刷新、切页和服务重启后可继续恢复任务。
- 商品幻境爆款撞色主图：现有数据卷升级后应自动出现该模板；选择不同商品时，模板要求中的商品名称应替换为当前名称，自动切换到卖点强化风格并仅选择对应主图。生成结果应包含米白与橙红撞色底部横幅、醒目大字号、左侧圆角卖点标签和 2-3 条已确认卖点，不得出现价格、折扣、限时促销角标、随机糊字、零食道具或其他跨品类元素。
- 商品幻境详情页：上传带白底或棚拍背景的商品图并完成分析，确认主图、卖点、场景和详情页提示词会主动重建商业背景，统一使用同一套色彩、光线、镜头和商品还原规则；默认只选择一张主图，可单独勾选某个详情页或按类别全选，重复详情类型会补齐卖点、细节、规格、信任和总结模块；模板会同步视觉风格与模板要求，1:1、3:4、4:3 结果在桌面和手机端均完整显示且没有横向溢出或空白拉伸卡片。
- 提示词优化：管理员可在渠道设置中选择专用文本模型，刷新和重启后应保留；普通用户前端不展示、不选择，也不能在请求中覆盖。分别在丹青台与画布图片节点使用摄影、东方玄幻、动漫、海报/电商和参考图编辑提示词，确认优化稿保持主体、数量、引号内文字与参考图编号；不点击“采用优化稿”时原文不变，优化失败时仍可直接生图，且修炼页面的生图用量不增加。
- 大参考图生图：在丹青台与画布分别上传 4 张约 8 MB 的参考图，确认提交时不再把服务端素材重复转成 Base64，请求可正常创建任务；删除或伪造其他用户素材引用时应返回无权访问或素材不存在，且不会创建任务、扣除额度或调用上游。

- 画布图片编辑器：分别打开裁剪、局部遮罩和切分弹窗，验证滚轮及按钮缩放、空格拖动画面、裁剪比例预设、遮罩画笔坐标与撤销重做、切分线拖动与撤销重做；关闭弹窗后再次打开应恢复初始状态，高分辨率图片预览不应闪烁或明显增加常驻内存。
- 上游 v0.11 兼容更新：在画布工具栏与画布空白处一次选择或拖入多张图片/视频/音频，确认按偏移位置分别创建且替换节点时其余文件不会丢失；左侧元素列表的图片预览按钮可打开大图；文本生成节点可选择自动/低/中/高/极高推理强度并在重新选中后保留；使用 Seedream/火山方舟参考图和返回 `images`/`results` 字段的渠道验证生图与错误反馈。
- 斗帝帝临视觉：分别使用斗帝与普通账户验证命宫境界意境 Banner、帝境法相、成长统计、境界阶梯、首页金印、顶部导航和画布顶栏身份徽章；帝境法相只对斗帝显示并应与右侧阶梯高度协调，斗帝命宫不应出现独立的居中深空舞台，徽章应打开身份卡与帝临设置，并可从卡片进入“我的修炼”，普通账户保持原有跳转。
- SPA 目录路由：直接打开或刷新 `/assets`，确认返回应用页面而不是空文件；同时抽查 `/image`、`/cultivation` 和带哈希的静态资源缓存不受影响。
- 丹青台历史记录：验证“历史”入口位于“生成结果”标题旁；批量删除不会触发请求限流，删除成功后跨标签页、刷新和换设备均不再出现，已入藏卷阁作品保持可用，视频生成中的记录删除后不会被轮询重新写回。
- 画布提示词库：验证左侧面板可按来源展开、跨来源搜索、查看详情并插入带原始标题的文本节点；节点生成完成后输入内容仍保留，资产和提示词 Tab 切换时不重复加载。
- 提示词来源：验证 Banana Prompt Quicker 可加载 323 条内容；来源配置显示数量、正常/失败状态和上次成功时间，刷新失败时旧缓存仍能继续浏览。
- Agent 图片附件：在右侧 Agent 上传参考图并要求创建生图流程，确认图片成为保持比例的真实画布节点且可参与生成；切换标签页时只能写入任务发起页，对话向上浏览时新消息不强制跳到底部。
- 生图分辨率、质量与格式：验证 `1K / 2K / 4K` 输出分辨率和独立生成质量可分别生效；兼容 GPT Image 的渠道可提交 `quality` 与 `output_format`，并正确保存 PNG、JPEG、WebP；UU `gpt-image-2` 异步渠道应保持模型自动质量与格式且不因该设置报错。
- 内嵌图片结果：使用会返回 Base64 JSON 的真实渠道分别验证 1K、2K、4K 单图结果可落盘；确认普通 API 响应仍受较小 JSON 上限保护，批量高分辨率图提示用户降低单次张数而不使服务器内存失控。

- 生图资产保存：使用真实生成结果验证“添加到资产”的保存中状态、成功入库、过期任务图片和上传失败提示。
- 生图状态与错误反馈：用成功、超时、限流、参数错误和上游临时不可用的真实渠道验证排队/提交/上游生成阶段、友好错误提示、部分成功结算和全失败自动退还。
- 渠道健康状态：在管理员「用量」页验证多用户同名渠道的区分、近 7 天成功率、平均耗时、运行中任务、最近错误和 30 秒自动刷新。
- SQLite 自动备份：验证首次启动约 60 秒后生成可打开的快照、每日调度、保留数量清理、管理员状态展示，以及停止容器后的快照恢复流程。
- 头像加载回退：分别用正常头像、慢速响应、404 和损坏图片验证导航、修炼页、后台列表与画布助手始终保留占位且成功后平滑淡入。
- UU 生图路由：使用真实 UU API 渠道验证单图文生图使用异步任务、单参考图使用标准编辑接口；覆盖提交、文生图刷新或切换页面、服务重启恢复、取消、失败重试与任务过期后的错误提示。
- 山海意境视觉：验证桌面与手机下的首页首屏、核心入口与更多导航、画布列表、生图/视频工作台、提示词库、资产操作、修炼页、配置页和后台；确认场景图加载正常、导航不遮挡、移动端无横向溢出，资产编辑/下载/删除仍可操作。
- 修炼成长系统：验证旧 `state.json` 首次启动迁移与失败回退、旧待审批用户自动续升、普通用户额度/并发/能力限制、任务成功结算与失败退款、跨境界自动突破、突破动画、个人修炼页，以及管理员无说明调整用户境界/修为/额度和配置/用量/日志页签。
- 安全公网模式：使用真实域名和 Caddy profile 验证 HTTPS、HSTS、登录 Cookie、成员停用、API Key 加密保存和跨用户项目/素材隔离。
- 持久生图任务：使用真实渠道提交长任务，分别测试切换页面、刷新、关闭后重开、取消、失败重试和服务重启后的状态恢复。
- 服务端项目与素材：在两台设备使用同一成员身份验证项目恢复、图片/视频可访问、revision 冲突提示、项目删除和数据卷备份恢复。
- 上传与能力校验：验证 16 MB 图片、5000 万像素、模型参考图上限、透明背景、1K/2K/4K 等不同模型能力边界。
- 构建与部署：在 GitHub Actions 验证 amd64/arm64 镜像、`stable`/版本标签、Compose healthcheck 及固定版本回滚。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
