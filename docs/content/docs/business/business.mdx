# 商务合作

本仓库目前没有公开私人邮箱、QQ 或固定商务渠道。旧版文档中的上游维护者联系方式不代表 `zdtzn/infinite-canvas` 当前维护者。

如需咨询私有化部署、模型渠道接入、二次开发或商业授权，请在当前仓库创建标题为 `[合作咨询]` 的 Issue，只描述非敏感的需求范围，并请求维护者提供私密联系方式。

公开 Issue 中不要提交：

- API Key、服务器登录信息或数据库备份。
- 真实用户数据、未脱敏日志或内部域名。
- 预算、合同、个人联系方式等不适合公开的信息。

项目仍按 [AGPL-3.0](/docs/business/license) 发布。涉及再分发、托管服务或闭源组合时，应自行评估并遵守许可证义务。
