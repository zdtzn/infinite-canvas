# 支持项目

当前仓库暂未公布收款码、私人邮箱、官方 QQ 群或固定广告赞助入口。请不要向上游 README、旧文档或第三方页面中的联系方式付款，并以本仓库后续正式公告为准。

目前可用的支持方式：

- 为 [zdtzn/infinite-canvas](https://github.com/zdtzn/infinite-canvas) 点 Star。
- 通过 Issue 提交可复现的问题和高质量改进建议。
- 修正文档、测试或兼容性问题，并按 [CLA](/docs/business/cla) 提交 Pull Request。

涉及非公开信息时，只在公开 Issue 中请求维护者提供私密渠道，不要直接附上 API Key、账号、服务器地址或真实用户数据。
